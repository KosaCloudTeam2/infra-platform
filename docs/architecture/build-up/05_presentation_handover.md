# 05 Presentation / Handover 상세 구현

담당: 전원

## 1. 목표

구현 결과를 각 담당자가 직접 설명하고 시연할 수 있는 스토리로 정리하고, 발표 후에도 팀원이 인프라를
이해하고 정리할 수 있도록 인계 자료를 완성함.

## 2. 산출물

- Marp 발표 원본
- PDF 발표 자료
- Demo Script
- Q&A
- 비용 정리
- 리소스 정리 계획
- 최종 Runbook 링크 모음
- 담당 영역별 시연 캡처와 설명 스크립트

1. 문제 정의

7. 관측성과 장애 대응
8. 비용과 한계
9. 향후 확장
