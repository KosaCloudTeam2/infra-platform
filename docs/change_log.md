## 작성 기준

- 최신 변경을 위에 작성함.
- 사소한 오탈자보다 설계, 구현 범위, 보안, 일정, 운영 절차에 영향을 주는 변경을 기록함.
- 변경이 Terraform, GitHub Actions, 보안 정책, 발표 시나리오에 영향을 주면 관련 문서를 함께 갱신함.
- 검증하지 못한 항목은 `검증/상태`에 사유를 남김.
