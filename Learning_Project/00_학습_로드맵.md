# 학습 로드맵 — kosa-tickets 프로젝트 기준

> 0부터 시작해서 발표까지 가는 학습 순서. 각 단원은 별도 문서로 분리되어 있음. **순서대로 따라가면
> 한 사람이 전체 인프라를 처음부터 구성 가능.**

---

## 학습 원칙

1. **추상 → 구체** — 개념 먼저, 그 다음 우리 환경
2. **이유 → 방법** — "왜 이걸 쓰나?" 먼저, 그 다음 "어떻게 쓰나?"
3. **대안과 비교** — 다른 선택지가 있는데도 이걸 고른 이유
4. **역할 명확화** — 이 컴포넌트가 전체 그림에서 뭘 하는가

## 단원별 상세

### 01. 네트워크 (VLAN, pfSense, HA)

- **시간**: 1일
- **선수 지식**: TCP/IP 기본, 라우팅 개념
- **핵심 질문**:
  - 왜 VLAN으로 분리하나? 하나의 네트워크에 다 두면 안 되나?
  - pfSense가 하는 일은 정확히 뭔가? 라우터/방화벽/DHCP?
  - CARP/HA는 왜 필요한가? 한 대로 충분하지 않나?
  - L2 vs L3 스위치 — 왜 우리는 L3 매니지드를 쓰나?
- **주요 기술**: VLAN, pfSense, CARP, VRRP, OSPF (선택), Spine-Leaf 패브릭
- **대안 비교**: Cisco IOS, MikroTik, OPNsense vs pfSense
- **문서**: [`01_네트워크_VLAN_pfSense.md`](01_네트워크_VLAN_pfSense.md)

### 02. 가상화 (Proxmox, Cloud-Init)

- **시간**: 1일
- **선수 지식**: 리눅스 기초, 가상화 개념
- **핵심 질문**:
  - Proxmox vs VMware vs KVM/QEMU — 왜 Proxmox?
  - 클러스터링 + HA는 어떻게 동작하나?
  - Cloud-Init이 왜 필수인가? 수동 설치는 안 되나?
  - 템플릿 VM과 일반 VM의 차이?
- **주요 기술**: Proxmox VE 8, QEMU/KVM, Cloud-Init, VLAN-aware bridge
- **대안 비교**: VMware ESXi, Hyper-V, OpenStack
- **문서**: [`02_가상화_Proxmox.md`](02_가상화_Proxmox.md)

### 03. 스토리지 (Ceph)

- **시간**: 1일
- **선수 지식**: RAID 개념, 분산 시스템 기초
- **핵심 질문**:
  - Ceph는 정확히 어떤 종류의 스토리지인가? (Block, File, Object 모두?)
  - RBD vs CephFS vs RGW — 언제 무엇을?
  - replicas vs erasure coding — 어떤 게 우리 환경에?
  - BlueStore와 FileStore의 차이?
- **주요 기술**: Ceph, RBD, BlueStore, CRUSH map, Placement Group
- **대안 비교**: GlusterFS, Longhorn, NFS, MinIO
- **문서**: [`03_스토리지_Ceph.md`](03_스토리지_Ceph.md)

### 04. K8s 핵심 (Control Plane, Worker, etcd)

- **시간**: 2일
- **선수 지식**: Docker, 컨테이너 개념
- **핵심 질문**:
  - K8s가 정확히 해결하는 문제는?
  - Control Plane 컴포넌트 5개 (API server, etcd, scheduler, controller, kube-proxy)
  - 왜 etcd가 3대 (또는 홀수)인가?
  - Pod, ReplicaSet, Deployment, StatefulSet — 언제 무엇을?
  - kubeadm vs kubespray vs k3s — 왜 kubeadm?
- **주요 기술**: kubeadm, etcd, kubelet, containerd, kube-proxy
- **대안 비교**: K3s, OpenShift, Rancher, kubespray
- **문서**: [`04_K8s_핵심.md`](04_K8s_핵심.md)

### 05. K8s 애드온 (Calico, MetalLB, HAProxy Ingress)

- **시간**: 1일
- **선수 지식**: 04번 단원 완료
- **핵심 질문**:
  - CNI가 뭔가? 왜 Calico를 골랐나? (Cilium, Flannel, Weave 대비)
  - MetalLB가 풀어주는 문제? (온프레미스의 LoadBalancer)
  - Ingress와 Service의 차이? (L4 vs L7)
  - HAProxy Ingress vs NGINX Ingress vs Traefik
- **주요 기술**: Calico CNI, MetalLB (L2/BGP), HAProxy Ingress, cert-manager
- **대안 비교**: Cilium, Flannel, NGINX Ingress, Traefik, Contour
- **문서**: [`05_K8s_애드온.md`](05_K8s_애드온.md)

### 06. DB & Cache (Percona, ProxySQL, Redis)

- **시간**: 2일
- **선수 지식**: MySQL 기본, 트랜잭션, 인덱스
- **핵심 질문**:
  - Percona XtraDB Cluster vs MySQL Group Replication vs Galera?
  - Operator 패턴이 뭔가? Operator vs 수동 StatefulSet?
  - ProxySQL이 푸는 문제? R/W 분리, 부하 분산
  - Redis Sentinel vs Cluster vs Standalone — 왜 Sentinel?
- **주요 기술**: PXC, ProxySQL, Redis Sentinel, Percona Operator
- **대안 비교**: Vitess, ProxySQL vs MaxScale, Redis Cluster
- **문서**: [`06_DB_Percona_ProxySQL_Redis.md`](06_DB_Percona_ProxySQL_Redis.md)

### 07. IaC (Terraform, Ansible)

- **시간**: 1일
- **선수 지식**: YAML, HCL 문법
- **핵심 질문**:
  - Terraform과 Ansible의 책임 분담? (선언적 vs 절차적, 인프라 vs 구성)
  - 왜 둘 다 쓰나? Terraform만 또는 Ansible만으론 안 되나?
  - state 파일 관리 — 로컬 vs S3 backend?
  - 멱등성(idempotency)은 어떻게 보장되나?
- **주요 기술**: Terraform, Ansible, bpg/proxmox provider
- **대안 비교**: Pulumi, CloudFormation, Chef, Puppet, SaltStack
- **문서**: [`07_IaC_Terraform_Ansible.md`](07_IaC_Terraform_Ansible.md)

### 08. GitOps (ArgoCD)

- **시간**: 1일
- **선수 지식**: Git, K8s 매니페스트
- **핵심 질문**:
  - GitOps가 정확히 뭔가? CIOps와의 차이?
  - ArgoCD vs Flux — 왜 ArgoCD?
  - App-of-Apps 패턴, ApplicationSet?
  - 멀티 클러스터 (온프레 + EKS) 어떻게 운영?
- **주요 기술**: ArgoCD, Application CR, ApplicationSet, Helm chart 통합
- **대안 비교**: Flux, Jenkins X, Spinnaker
- **문서**: [`08_GitOps_ArgoCD.md`](08_GitOps_ArgoCD.md)

### 09. AWS 하이브리드 (VPC, NLB, VPN, EKS, RDS)

- **시간**: 3일
- **선수 지식**: AWS 기본 (EC2, VPC), K8s
- **핵심 질문**:
  - 왜 하이브리드 클라우드인가? 풀 클라우드 또는 풀 온프레가 아니라?
  - AWS Edge 패턴 vs Cloud Bursting — 차이?
  - Site-to-Site VPN vs Direct Connect — 왜 VPN?
  - Karpenter vs Cluster Autoscaler — 왜 Karpenter?
  - Percona binlog → RDS Read Replica 복제 메커니즘?
- **주요 기술**: AWS VPC, NLB, EC2 HAProxy, IPsec VPN, EKS, Karpenter, RDS, Route 53
- **대안 비교**: Direct Connect, AWS Outposts, GCP Anthos
- **문서**: [`09_AWS_하이브리드.md`](09_AWS_하이브리드.md)

### 10. 모니터링 (Prometheus, Grafana, JMeter)

- **주요 기술**: Prometheus, Grafana, kube-state-metrics, node-exporter, JMeter
- **대안 비교**: Datadog, New Relic, CloudWatch
- **문서**: [`10_모니터링_Prometheus_Grafana.md`](10_모니터링_Prometheus_Grafana.md)

| ---------- | ------------------------------ | ------------------------------------------- |
| 🟢 발표 OK | 발표 때 설명 가능한 수준       | "VLAN으로 보안 격리, pfSense가 HA로 라우팅" |
| 🟡 운영 OK | 실제 운영/디버깅 가능          | pfSense 룰 추가/수정, VLAN 트래픽 분석      |
| 🔴 설계 OK | 새 환경에서 처음부터 설계 가능 | VLAN 대역 + DHCP + 방화벽 룰 통째 설계      |

**최소 목표**: 모든 단원 🟢, 본인 담당 영역 🔴.

- A (본인): 네트워크 + IaC + 발표 = 1, 7, 11

- C: DB + 모니터링 + 시나리오 = 6, 10

## 학습 자료 활용법

각 단원 문서 안에 다음 섹션이 있어:

1. **개념** — 그림 + 정의
2. **왜 필요한가** — 이 기술이 풀어주는 문제
3. **어떻게 동작하는가** — 내부 원리
4. **대안과 비교** — 다른 선택지
5. **우리 환경에서** — `project/` 문서로 링크
6. **실습** — 직접 만져보는 명령
7. **발표 어필 멘트** — 그대로 발표 자료에 옮길 수 있는 문장
8. **추가 학습** — 공식 docs, 책, 영상 링크

처음 읽을 땐 1~5만, 발표 직전엔 7만 빠르게 복습.
