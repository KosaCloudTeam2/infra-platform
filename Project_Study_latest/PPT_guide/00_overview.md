## 디자인 원칙 — 가독성 우선

1. **한 슬라이드 = 한 메시지**
2. **본문 단위 ≤ 5개** (카드 5개 또는 항목 5개 넘으면 분리)
3. **KPI는 1~3개만**
4. **여백을 두려워하지 않기**
5. **시각 위계 = 1 헤드라인 + 1 큰 그래픽 + (선택) 보조 텍스트**

## 발표자 간 바톤 넘기기

각 파트 마지막 슬라이드에 다음 발표자에게 자연스럽게 패스하는 한 줄을 깔아두기.

- A → B: "이 위에 데이터가 어떻게 흐르는지는 ○○님이"
- B → C: "데이터 layer가 준비됐으니, 그 위에서 코드가 어떻게 배포되는지는 ○○님이"
- C → D: "배포까지 봤으니, 마지막으로 이걸 안전하게 막는 보안 계층을 ○○님이"
