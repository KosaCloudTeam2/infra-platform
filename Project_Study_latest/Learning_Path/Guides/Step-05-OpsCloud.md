# [Step 5] 운영의 실제와 클라우드 확장 (Guide)

## 1. 시스템 관측성(Observability) 확보

- Prometheus 기반 메트릭 수집
  - 서버 및 파드 상태(CPU, 메모리, 트래픽 등) 실시간 수집
  - K8s 시스템 컴포넌트 외부 접근 허용을 위한 0.0.0.0 바인딩 튜닝 실시
- Grafana 기반 데이터 시각화
  - 수집 데이터의 그래프 및 대시보드 시각화
  - 시스템 상태의 직관적 파악 환경 구축

## 2. 장애 대응 검증(Validation) 수행

- HA(고가용성) 기능 정상 동작 여부 테스트
  - pfSense 방화벽 정지 시 서비스 유지 확인 (CARP 테스트)
  - K8s 노드 정지 시 서비스 연속성 확인 (Rollout 테스트)
- 모의 훈련을 통한 시스템 신뢰성 확보 완료

## 3. AWS 하이브리드 확장 구축

- 전용 터널(Site-to-Site VPN) 연동
  - 온프레미스와 AWS 간 사설망 통신 환경 조성
  - pfSense의 AWS 대역 트래픽에 대한 NAT Bypass 설정 적용
- 클라우드 Bursting 구현
  - 피크 트래픽 발생 시 AWS 자원 기반 파드 확장 및 부하 분산

## 4. 설계의 트레이드오프(Trade-off) 분석 및 마무리

- 온프레미스의 비용 효율성과 클라우드의 확장성 간 최적 균형 달성
- 운영 환경의 안정성과 유연성 동시 확보

## 5. 발표용 핵심 포인트 (Talking Points)

- Prometheus/Grafana 기반 클러스터 전역 실시간 모니터링 체계 구축 완료
- CARP 및 Keepalived 기반 HA 기능의 실질적 페일오버 검증 완료
- AWS VPN 연동을 통한 하이브리드 클라우드 확장 모델 완성
