# [Step 2] 소프트웨어 정의 스토리지 (Ceph) (Guide)

1. 인프라 핵심 요소로서의 데이터 관리

- 데이터 가용성 및 안전성 확보를 위한 Ceph 분산 스토리지 도입

2. Ceph: 분산 스토리지 통합 관리

- 여러 서버의 물리 디스크를 단일 스토리지 풀로 통합
- 다중 인터페이스 제공
  - RBD(Block): 일반 하드디스크 형태의 블록 스토리지
  - CephFS(File): 파일 서버 형태의 파일 시스템
  - RGW(Object): S3 호환 클라우드 형태의 객체 스토리지
- 유연한 확장성: 서버 및 디스크 추가를 통한 클러스터 용량 증설 용이

3. CRUSH 알고리즘 기반 데이터 저장 방식

- 수학적 계산(CRUSH)을 통한 데이터 위치 결정 및 관리
- 중앙 서버 병목 현상 제거 및 모든 노드에서의 데이터 위치 계산 가능

4. 3-Replica 데이터 보호 전략

- 데이터를 서로 다른 3개 서버에 중복 저장함 (3-Replica)
- 최대 2대의 서버 동시 장애 발생 시에도 데이터 100% 보존 및 서비스 연속성 보장

5. 프로젝트 내 주요 활용 사례

- K8s 블록 스토리지 (RBD): MySQL, Redis 등 DB 데이터 저장 및 파드 이동 시 영속성 유지
- Harbor 이미지 저장소 (RGW): 사내 컨테이너 이미지 저장을 위한 S3 호환 백엔드 활용

6. 핵심 발표 요약 (Talking Points)

- Ceph 3-Replica 운영을 통한 극대화된 데이터 가용성 강조
- RBD 및 RGW 동시 제공을 통한 통합 스토리지 관리 효율성 부각
- CRUSH 알고리즘을 통한 성능 최적화 및 확장성 확보 설명
